# 人員収支シミュレーター

オアシス第二病院・重度認知症デイ向けの人員収支シミュレーターです。  
このサイトは静的HTMLとして動作し、GitHub Pages で公開できます。

## 機能
- 利用者数・単価・加算・営業日数の入力
- その他経費・目標利益率の入力
- 職種別人件費と現在人数の管理
- 損益分岐点と目標利益率達成に必要な人数試算
- 職種別の不足/余剰判定

## 使用方法
1. `index.html` をブラウザで開く
2. 数値を入力して「計算する」を押す
3. 結果と職種別判定を確認する

## GitHub Pages
このリポジトリでは、Settings → Pages から GitHub Pages を有効化すれば公開できます。
